# 📝 NotesApp - Приложение для заметок

## 📚 Описание
**NotesApp** — это полнофункциональное приложение для создания, редактирования и управления заметками с поддержкой напоминаний, базы данных и многооконного интерфейса.

## 🎯 Функционал приложения

| Функция | Описание |
|---------|----------|
| ✏️ Создание заметок | Добавление новых заметок с заголовком и содержанием |
| 📝 Редактирование | Изменение существующих заметок |
| 🗑 Удаление | Удаление заметок (долгое нажатие или кнопка) |
| ⏰ Напоминания | Установка даты и времени для уведомления |
| 🔔 Уведомления | Push-уведомления в указанное время |
| 📋 Список заметок | Все заметки отображаются в виде карточек |
| 🔄 Обновление | Swipe-to-refresh для обновления списка |
| 💾 База данных | Локальное хранение с Room Database |

---

## 🛠️ Технологии

- **Язык:** Java
- **Минимальная версия Android:** API 24 (Android 7.0)
- **Среда разработки:** Android Studio
- **База данных:** Room Database (SQLite)
- **UI компоненты:** RecyclerView, CardView, FloatingActionButton
- **Уведомления:** AlarmManager + BroadcastReceiver
- **Многопоточность:** ExecutorService
